# Crypto Radar — парсер крипто-новостей с сортировкой по интересности

Собирает новости из ~50 источников, склеивает дубли, оценивает каждую новость
и раскладывает по трём блокам: **🔥 Горячие → ⚡ Интересные → 📊 Средние**.
Плюс теги: инсайды, киты, новые монеты, листинги, тренды, регуляторы, взломы,
институционалы, макро, ончейн.

Мобильная лента: `docs/` (GitHub Pages). Сбор данных: GitHub Actions по расписанию.

---

## Ответы на твои вопросы

### Нужна ли база вроде Supabase?

**Сейчас — нет.** Лента статическая: парсер раз в 30 минут пишет
`docs/data/feed.json`, а страница его читает. Supabase в этой схеме был бы
пятым колесом — платить и настраивать за то, что делает обычный JSON-файл.

Локальный SQLite (`data/news.db`) используется только для памяти между
запусками: что уже показывали (метка «new»), снимок списка монет CoinGecko
(чтобы находить новые листинги), история скоров. Файл восстановимый, поэтому в
Actions он лежит в кэше, а не в репозитории.

Supabase (или любой Postgres) понадобится, когда появится что-то из этого:

| Что понадобится | Почему нужна БД |
| --- | --- |
| Аккаунты, личные фильтры, подписки | нужно писать данные с клиента |
| Push-уведомления «горячая новость» | нужен сервер и хранилище токенов |
| История за месяцы с поиском и графиками | JSON-файл станет тяжёлым |
| Несколько устройств пишут в одно состояние | появляются конкурентные записи |

Переезд подготовлен: вся работа с хранилищем — в одном файле
`cryptoparser/store.py`. Меняется он, остальной код не трогается.

### Хватит ли подписки Pro за $20?

Для **разработки** — да, этой подписки достаточно.

Дальше важная деталь, чтобы не было сюрприза в счёте: **подписка Claude Pro и
Anthropic API — это разные вещи, токены API в подписку не входят.** Поэтому
парсер спроектирован так, чтобы работать вообще без API:

| Что | Стоимость |
| --- | --- |
| Сбор новостей (RSS, Reddit, Google News) | $0, ключи не нужны |
| Ранжирование и категории (эвристики) | $0, считается локально |
| Тренды, новые монеты, топ-движения (CoinGecko) | $0, публичный API |
| Потоки стейблов и TVL (DefiLlama) | $0, без ключа |
| Хостинг ленты (GitHub Pages) | $0 |
| Запуски парсера (GitHub Actions) | $0 на публичном репозитории |
| **Итого регулярных расходов** | **$0** |

Опционально: `USE_LLM_RERANK=1` включает переранжирование топ-30 через Claude
API — модель пересобирает порядок и пишет хук для поста на русском. Это уже
оплата за токены (порядка нескольких центов за запуск), поэтому по умолчанию
выключено. Такой же опциональный `ETHERSCAN_API_KEY` (бесплатный ключ)
добавляет крупные переводы ETH на биржи и с них.

## Как это работает

```
источники ──▶ загрузка ──▶ склейка сюжетов ──▶ скоринг ──▶ тиры ──▶ feed.json ──▶ страница
   RSS          парал-        похожие            7 ком-      порог     статика      мобильная
   Reddit       лельно        заголовки          понентов    + топ-N   в docs/      вёрстка
   Google News                в один сюжет
   CoinGecko
   DefiLlama
```

### Из чего складывается оценка

Скор 0–100, семь независимых компонентов, каждый ограничен сверху — так один
сигнал не может перевесить всё остальное (`cryptoparser/score.py`):

| Компонент | Максимум | Что означает |
| --- | --- | --- |
| Авторитет источника | 15 | The Block и CoinDesk весят больше, чем агрегаторы |
| Ключевые сигналы | 55 | словари по 10 темам с затуханием повторов |
| Масштаб | 18 | размер суммы в тексте: `$2.1B` весит больше `$5M` |
| Крупные имена | 12 | BlackRock, SEC, Binance, BTC, ETH |
| Свежесть | 14 | период полураспада 7 часов |
| Подтверждения | 14 | сколько независимых источников написали о том же |
| Ончейн-бонус | 10 | для сигналов из рыночных модулей |
| Штрафы | −38 | реклама, «топ-5 монет», прогнозы цены, пересказы |

В каждой карточке видно, **почему** новость на этом месте: раскрывающийся блок
показывает вклад каждого компонента. Это не украшение — так сразу видно, если
ранжирование сломалось.

### Склейка сюжетов

Одно событие в пяти изданиях — это не пять новостей, а один сюжет и сильный
признак «горячего». Заголовки нормализуются, сравниваются метрикой
`½ Jaccard + ½ перекрытие`, и при совпадении с любым участником сюжета запись
подклеивается к нему. Порог — `CLUSTER_SIMILARITY`.

Пример из тестового набора: три разных заголовка про одобрение Solana ETF
(The Block, CoinDesk, Blockworks) собираются в одну карточку с пометкой
«3 источника» и уходят на первое место.

## Запуск локально

```bash
git clone https://github.com/neritsyannoro-beep/Parcer.git
cd Parcer
pip install -r requirements.txt

python -m cryptoparser.main          # собрать ленту в docs/data/feed.json
python -m http.server -d docs 8000   # открыть http://localhost:8000
```

Прогон без интернета — на тестовом наборе заголовков:

```bash
python tests/make_fixtures.py
python -m cryptoparser.main --fixtures tests/fixtures
```

Полезные флаги: `--no-market` (без ончейн-модулей), `--limit N`, `--out PATH`, `-v`.

## Публикация

1. **Pages:** Settings → Pages → Source: `Deploy from a branch`, ветка `main`,
   папка `/docs`. Через минуту лента доступна по адресу
   `https://neritsyannoro-beep.github.io/Parcer/`.
2. **Расписание:** воркфлоу `.github/workflows/parse.yml` запускается каждые
   30 минут. GitHub исполняет cron **только на ветке по умолчанию** — пока код
   в отдельной ветке, запускай вручную через Actions → «Парсинг новостей» → Run workflow.
3. **Ключи (не обязательно):** Settings → Secrets and variables → Actions →
   `ETHERSCAN_API_KEY`, `COINGECKO_API_KEY`, `ANTHROPIC_API_KEY`.
   Переменная `USE_LLM_RERANK=1` включает LLM-переранжирование.

## Настройка под себя

| Что поменять | Где |
| --- | --- |
| Пороги «горячее/интересное», окна времени, размер ленты | `cryptoparser/config.py` |
| Веса тем, ключевые фразы, штрафы за клик-бейт | `cryptoparser/keywords.py` |
| Добавить/убрать источник, поисковые запросы Google News | `cryptoparser/sources.py` |
| Формула скора, склейка сюжетов | `cryptoparser/score.py` |
| Рыночные и ончейн-сигналы | `cryptoparser/market.py` |
| Шаблон поста для X | `render.build_tweet` |
| Вёрстка и тема | `docs/style.css`, `docs/app.js` |

Начни с `TIER_HOT_THRESHOLD` (по умолчанию 68) — если «горячих» слишком много,
поднимай; если лента выглядит пустой, опускай. `MIN_HOT` гарантирует, что
верхний блок никогда не окажется пустым.

## Структура

```
cryptoparser/
  config.py     все настройки в одном месте
  sources.py    реестр источников (RSS, Reddit, Google News)
  fetch.py      параллельная загрузка и нормализация
  keywords.py   словари сигналов и штрафов
  score.py      скоринг, склейка сюжетов, тиры
  market.py     CoinGecko, DefiLlama, Etherscan
  store.py      SQLite: память между запусками
  llm.py        опциональное переранжирование через Claude API
  render.py     сборка feed.json и черновиков постов
  main.py       точка входа
docs/           мобильная лента для GitHub Pages
tests/          генератор фикстур для офлайн-прогона
```

## Про источники и ограничения

Профильные редакции (The Block, CoinDesk, Blockworks, Cointelegraph, Decrypt и
далее), Reddit (r/CryptoCurrency, r/CryptoMoonShots и другие) и запросы Google
News — последние закрывают требование «из всех источников»: через них попадают
Reuters, Bloomberg, Forbes и всё, что индексирует Google.

Честно про ограничения:

- **«Инсайды» — это публичные утечки и материалы со ссылкой на источники,**
  а не приватная информация. Настоящий инсайд по определению не лежит в RSS.
- **Заголовки на английском.** Русский хук пишется только при включённом
  LLM-переранжировании; эвристики язык не переводят.
- **Киты без платных API видны частично:** переводы ETH требуют бесплатного
  ключа Etherscan, а данные по остальным сетям заменяются потоками стейблов,
  движением TVL и упоминаниями в новостях.
- **Новые монеты** определяются диффом списка CoinGecko: первый запуск только
  фиксирует базовый снимок, находки начинаются со второго.
- **Проверяй перед публикацией.** Высокий скор означает «похоже на важное», а
  не «проверено». Для новых токенов особенно: контракт и ликвидность руками.
